// Windows Desktop App

Mess Management · JAH Mess

Private client · UAE

A custom offline-first Windows desktop app for a UAE mess (meal-subscription) business. Tracks customers, categories, dues and advance, with pro-rated monthly billing, finance logs, inventory and CSV report exports — all in a polished neumorphic UI, stored in local SQLite with zero cloud cost. Ships as a signed, machine-locked installer with automatic backups.

ResultDelivered as a signed .exe installer to a UAE client — a 7,000 AED contract, fully offline with no recurring hosting fees.
What's inside
  • Dashboard with live stats, charts and recent payments
  • Customer management — profiles, dues, advance and active/inactive status
  • Mess subscriptions with pro-rated billing (full-month vs per-day)
  • Income/expense finance module and monthly CSV report exports
  • Inventory control, camera photo capture and auto-backup
  • Offline machine-locked licensing (SHA-256) and Inno Setup installer
Stack
Flutter Dart SQLite (sqflite_ffi) fl_chart Inno Setup
